    Monitorizare când aplicația este închisă

    Serverul poate citi contul Invest la fiecare cinci minute și păstra alerte la stop, apropiere de stop, țintă, concentrare, modificări de poziții și erori. Folosește conexiunea Trading 212 deja salvată în cloud și ultimele repere sincronizate.

    Verific serviciul de monitorizare…

    Alertele se păstrează în acest inbox, inclusiv când telefonul este închis. Notificările push se activează separat pe fiecare dispozitiv, în secțiunea de mai jos. Deconectarea Google nu oprește monitorul; folosește „Oprește monitorizarea” înaintea deconectării. Prețul este cel raportat de broker la citire, fără timestamp individual verificat; nu este un flux tick. Stopurile sunt repere de reevaluare, fără execuție automată. Modelele AI nu sunt recalculate pe server. O verificare la cinci minute poate rata o atingere între citiri.

    Alerte pe telefon și PC

    Activează notificările acestui dispozitiv și permite-le în browser. Alertele conțin un mesaj generic; detaliile financiare rămân în inbox. Pentru alerte automate, activează și monitorizarea Invest de mai sus.

    Verific push…

    Acceptarea de către serviciul push nu confirmă primirea. Browserul confirmă separat primirea și deschiderea; acestea pot lipsi dacă telefonul este offline sau blochează notificările. Deconectarea Google păstrează abonamentul acestui dispozitiv; oprește notificările înainte de schimbarea contului.

    Verificarea funcționării

    Vezi ce este confirmat pe acest dispozitiv și ce pas mai trebuie făcut. Testul stocării salvează și recitește valori temporare separate de registrele personale.

    Raportul de diagnostic exclude identitatea contului, deținerile, soldurile, cheile API și abonamentele push. O verificare reală PC ↔ Android cere o modificare proprie văzută pe ambele dispozitive, cu același cont Google. Primirea notificărilor se confirmă separat pe fiecare dispozitiv.

    Backup complet și restaurare

    Descarcă datele acestui dispozitiv: jurnal, cont, planuri, setări, watchlist, rapoarte AI și registrele estimărilor, inclusiv copiile păstrate separat în browser. Funcționează și fără sincronizare activă.

    Alegerea fișierului produce doar previzualizarea. Registrele identice se păstrează; cele diferite cer selecție explicită.

    Ce se întâmplă la restaurare

    Registrele selectate înlocuiesc copiile locale corespunzătoare. Cele neselectate și datele absente din fișier rămân păstrate. În registrul estimărilor, originalele locale se păstrează și se adaugă numai estimările lipsă. Estimările adăugate sunt marcate ca restaurate, cer reverificare și nu activează învățarea probabilistică.

    Se păstrează o copie înaintea modificării. Dacă salvarea eșuează, aplicația încearcă recuperarea; după o întrerupere poți folosi „Recuperează copia anterioară”. Recuperarea păstrează modificările apărute ulterior, fără să le suprascrie. Copia de recuperare este înlocuită la începutul unei restaurări noi.

    Închide celelalte ferestre ale aplicației înainte de restaurare și nu edita datele până la finalizare. Sincronizarea se suspendă pentru a permite verificarea datelor; după reîncărcare, „Sincronizează acum” o reia. Datele restaurate își păstrează orele sursei.

    Backupul este un fișier personal JSON și include datele financiare. Cheile API, sesiunile Google, setările de rețea și cache-ul cotațiilor sunt excluse. Conexiunea Trading 212 se recuperează separat prin același cont Google. Manifestul verifică integritatea conținutului, fără să certifice autenticitatea capturilor. Alertele păstrate exclusiv pe server rămân în inboxul cloud.

    Controlul datelor

    Înainte de aplicarea modificărilor cloud se păstrează până la cinci copii locale. Deconectarea Google oprește sincronizarea; datele și conexiunea locală Trading 212 rămân pe dispozitiv.

    Administrarea conexiunii Trading 212

    „Elimină conexiunea cloud Trading 212” șterge cheia și secretul din cloud și de pe acest dispozitiv. Alte dispozitive pot păstra copia lor locală; șterge conexiunea și acolo sau revocă cheia în Trading 212.

    Pe telefon: Mai multe → Cont & sincronizare. În modul offline, modificările rămân local și se reconciliază după revenirea online. Monitorizarea server este opțională și se confirmă prin ora ultimei rulări a schedulerului.
