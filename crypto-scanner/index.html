🔄 GitHub Gist Sync
Sincronizează cross-device: watchlist + alerte + config. Folosește un Gist privat ca storage.
GitHub Personal Access Token (scope: gist)
Generează la github.com/settings/tokens → Tokens (classic) sau Fine-grained → scope/permission "gist" only.
Gist ID (gol = creează unul nou)
Pe device 1: lasă gol, click "🆕 Creează gist". Pe device 2: copiază ID-ul de pe device 1 aici, apoi click "⬇ Pull".
Ce se sincronizează: watchlist live (+ filtre/sortare), alerte preț, scanner config, filtre Premium, Pump Radar, Smart Trade Long, Telegram config, dark mode, sortare, catalyst dismissals.
Ce NU se sincronizează: cheia API Anthropic (strict device-local — GitHub Secret Scanning ar revoca-o), token-ul + gistId, istoric semnale, snapshot-uri backup local.
